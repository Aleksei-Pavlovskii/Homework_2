# Homework-16.1

Проект представляет собой систему для управления товарами и категориями интернет-магазина, реализованную на Python с использованием объектно-ориентированного программирования.

## Основные классы

### Product (Базовый класс товара)

**Атрибуты:**
- `name` (str) - название товара
- `description` (str) - описание товара
- `price` (float) - цена товара (защищенный атрибут)
- `quantity` (int) - количество товара на складе

**Методы:**
- `__init__()` - инициализация товара
- `__str__()` - строковое представление товара
- `__add__()` - сложение товаров (по общей стоимости)
- `new_product()` - класс-метод для создания/обновления товара
- Свойства `price` с геттером и сеттером для валидации цены

### Smartphone (Наследник Product)

**Дополнительные атрибуты:**
- `efficiency` (float) - производительность
- `model` (str) - модель
- `memory` (int) - объем памяти
- `color` (str) - цвет

### LawnGrass (Наследник Product)

**Дополнительные атрибуты:**
- `country` (str) - страна-производитель
- `germination_period` (str) - срок прорастания
- `color` (str) - цвет

### Category (Категория товаров)

**Атрибуты:**
- `name` (str) - название категории
- `description` (str) - описание категории
- `products` (list) - список товаров (приватный атрибут)
- `category_count` (int) - счетчик категорий (классовый атрибут)
- `product_count` (int) - счетчик товаров (классовый атрибут)

**Методы:**
- `__init__()` - инициализация категории
- `__str__()` - строковое представление категории
- `add_product()` - добавление товара в категорию
- Свойство `products` для получения товаров в виде строки
- Свойство `products_in_list` для получения списка товаров

### ProductsIterator (Итератор для продуктов)

Реализует протокол итератора для последовательного обхода списка продуктов.

## Особенности реализации
### Валидация данных
+ Цена товара не может быть нулевой или отрицательной

+ При попытке установить цену ниже текущей требуется подтверждение пользователя

+ Проверка типов при добавлении товаров в категорию

### Функциональность
+ Автоматический подсчет количества категорий и товаров

+ Поддержка сложения товаров по общей стоимости

+ Обновление существующих товаров при добавлении дубликатов

+ Чтение данных из JSON файлов

### Инструменты разработки
Проект включает конфигурации для:

+ Black - форматирование кода

+ isort - сортировка импортов

+ flake8 - проверка стиля кода

+ mypy - статическая типизация

+ pytest - тестирование

### Пример использования
```
# Создание товаров
phone = Smartphone("iPhone", "Смартфон", 999.99, 10, 2.5, "15 Pro", 256, "Black")
grass = LawnGrass("Газонная трава", "Для сада", 49.99, 100, "Россия", "14 дней", "Зеленая")

# Создание категории
electronics = Category("Электроника", "Техника и гаджеты")
electronics.add_product(phone)

# Вывод информации
print(phone)
print(electronics)
```
